# ITZFIZZ — Scroll-Driven Hero Section

A responsive scroll-driven hero section built for the Itzfizz Web Development Internship assignment.

## Tech Used

- HTML5
- CSS3
- JavaScript
- GSAP 3
- GSAP ScrollTrigger

## Features

- Letter-spaced WELCOME ITZFIZZ hero heading
- Smooth initial load animation
- Staggered statistics reveal
- Scroll-driven main visual movement
- Transform-based movement for smoother performance
- Floating UI cards
- Scroll progress indicator
- Responsive mobile layout
- Reduced-motion accessibility fallback
- No build process required

## How to Run

Simply open `index.html` in a browser.

The project loads GSAP from jsDelivr, so an internet connection is required for the GSAP animations.

## GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Open repository Settings.
4. Open Pages.
5. Under Build and deployment, choose:
   - Source: Deploy from a branch
   - Branch: `main`
   - Folder: `/ (root)`
6. Save and wait for GitHub Pages to publish the site.
7. Copy the live URL into the internship form.
